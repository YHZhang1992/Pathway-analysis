# Preserved visualization contract

The portable figures retain the dominant conventions found in the supplied reports:

- white background with restrained grey grid/axes, corresponding to `theme_bw()` / `theme_minimal()`;
- Liberation Sans/Arial-compatible typography at an 11–13 point equivalent;
- reference/control blue `#1F77B4` and active/comparison red `#D62728`;
- positive/eligible green `#009E73`, warning/discordant orange `#D55E00`, neutral grey `#9AA5AA`;
- legends below multi-series plots when present;
- plot source data and run manifest stored beside each figure.

New chart types should follow this contract unless a study-specific source manifest records a different approved palette.
